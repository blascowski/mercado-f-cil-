# 🛒 Mercado Fácil

Projeto acadêmico de prototipação rápida de aplicações com HTML, CSS e JavaScript.

## Objetivo
Criar uma interface simples para simular a experiência de um mercado online, permitindo pesquisar produtos, filtrar categorias e calcular o valor de uma compra.

## Funcionalidades
1. Tela inicial com apresentação do mercado.
2. Janela de acesso demonstrativo com nome e e-mail.
3. Catálogo de produtos com pesquisa e filtros por categoria.
4. Carrinho com inclusão, remoção, quantidade e cálculo do total.
5. Finalização de pedido demonstrativa e mensagens de confirmação.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Não é necessário instalar dependências.

## Publicar no GitHub Pages
1. Abra **Settings** no repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a publicação.

## Observação
Este projeto é um protótipo visual para fins acadêmicos. O login não cria contas reais, e os pedidos não são enviados para um servidor nem processam pagamentos.
